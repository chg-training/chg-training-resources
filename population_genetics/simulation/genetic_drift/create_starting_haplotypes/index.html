Create some starting haplotypes

There isn't really anything about genetics in the basic Wright-Fisher model. So to give ourselves some genetic data to work with, we'll start by generating a set of haplotypes and have them evolve through the model.

Let's imagine we are looking at set of L = 20 SNPs to start with and that there are (say) up to 10 different haplotypes in our population at the start of the simulation. We'll create a matrix to put a simulated set of haplotypes:

L = 20
H = 10
haplotypes = matrix( NA, nrow = H, ncol = L )
L = 20
H = 10
# NB: create & fill the haplotypes in one step, below

To generate some simple haplotypes to look at, let's take a simple situation in which the variants are all biallelic (we'll encode the alleles as 0 or 1), they all start off independent of each other, and they all have 20% frequency. We can simulate by random sampling from the binomial distribution. R being a statistical programming language, the rbinom function is built-in, but Python is a more general language, so we need to load the "Numerical Python" library, numpy.


haplotypes[,] = rbinom(n=H*L, size=1, prob=0.2)
import numpy as np
haplotypes = np.random.binomial(1, p=0.2, size=(H, L))

Here's a function to make a quick plot of our starting haplotypes. R has built-in graphics, but in Python we will use the matplotlib library, specifically its pyplot module.



plot.haplotypes <- function( haplotypes ) {
  image(
    t(haplotypes),
    x = 1:ncol(haplotypes),
    y = 1:nrow(haplotypes),
    xlab = "variant",
    ylab = "haplotype"
  )
}
import matplotlib.pyplot as plt

def plot_haplotypes(haplotypes, title=None, ax=None):
  # matplotlib plots on an "axes" object, called `ax`.
  if ax is None:
    fig, ax = plt.subplots()

  colormap_used_by_R = "YlOrRd"
  ax.imshow(haplotypes, cmap=colormap_used_by_R, aspect="auto")
  ax.set(xlabel='variant', ylabel='haplotype', title=title)
  return ax

If you call it

plot.haplotypes( haplotypes )
ax = plot_haplotypes(haplotypes)
