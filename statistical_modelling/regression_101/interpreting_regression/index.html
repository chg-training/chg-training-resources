Interpreting regression output

Whichever flavour of regression you run, you'll get output looking like a big table of numbers, something like this:

# A tibble: 3 × 5
  term             estimate std.error statistic  p.value
  <chr>               <dbl>     <dbl>     <dbl>    <dbl>
1 (Intercept)       -0.0147    0.0224    -0.658 5.12e- 1
2 my_X_variable      0.239     0.0299     7.99  2.82e-12
3 another_variable   0.0342    0.0201     1.70  9.22e- 2

How should we interpret that?

In one sense, interpreting these results is the same for all regression models. For example, here we see that:

  • The estimated association between XXX and the YYY variable is 0.2390.2390.239;
  • The estimated standard error, which reflects how uncertain the model is about the estimate, is 0.02990.02990.0299;
  • And, as a result, the P-value (which reflects "how likely such a big estimate was if there were no true association" ) is pretty small in this example - p-value=2.8×10−12\text{p-value} = 2.8\times 10^{-12}p-value=2.8×10−12.

(In other words, such a strong association seems vanishingly unlikely 'by chance'.)

However, the differences between regression models come when you want to interpret the estimates in terms of the original variable YYY. This is because of the different link functions used for the different types of regression, which means that the linear predictor (and so the parameters) are on different scales.

## Interpretaiton in specific models

Linear regression​

For linear regression, the "link" function is just the identity function, y=xy=xy=x, and so the estimates are on the same scale as YYY. The parameter interpretation is:

Intercept: "the estimated mean value of YYY, when all the other predictors are 000.".

Other parameters: "the estimated change in YYY associated with a unit increase in the predictor".

But this is probably easier to remember using a picture:

The picture shows what is going on - the linear regression model tries to find a line of 'best fit' between the predictor variables and YYY, and the parameters are the parameters of this line. (If there are more than one XXX variable, it becomes multi-dimensional, so it's a 'plane' rather than a line.)

Logistic regression​

For logistic regression, there's a nontrivial link function to worry about. In short, the logistic function

logistic(x)=ex1+ex\text{logistic}(x) = \frac{e^x}{1+e^x}logistic(x)=1+exex​

is used to map the linear predictor, which is on the log-odds scale, to a probability, which is then used in the binomial distribution. Here it is again:

To understand this, let's try going the other way, from a probability ppp to the predictor scale. It works like this: first, convert the probability to an odds:

odds(p)=p1−p(this lies in the range [0,∞])\text{odds}(p) = \frac{p}{1-p} \qquad\text{(this lies in the range $[0, \infty]$)}odds(p)=1−pp​(this lies in the range [0,∞])

and then take a logarithm to get it in the range (−∞,∞)(-\infty, \infty)(−∞,∞):

logodds(p)=log⁡(p1−p)(this lies in the range [−∞,∞])\text{logodds}(p) = \log\left( \frac{p}{1-p}\right) \qquad\text{(this lies in the range $[-\infty,\infty]$)}logodds(p)=log(1−pp​)(this lies in the range [−∞,∞])

This probability-to-logodds mapping looks like this:

In the regression model terminology this is the link function, and the logistic function is its inverse.

In a sense, log-odds is just a useful way of representing a probability - as something that can take any real number value. To get back to a probability back you use the logistic function.

What this means for the regression result is:

The intercept is interpreted as: the modelled log-odds of YYY, when all the other predictors are 000; and

The other parameters are interpreted as: "the change in log-odds, or log⁡(odds ratio)\log\left(\text{odds ratio}\right)log(odds ratio), associated with a unit increase in the predictor."

Easy?

Poisson regression​

For Poisson regression, there's also a nontrivial link function to worry about - the logarithm function. It maps the Poisson rate parameter, which is positive, onto log⁡(rate)\log(\text{rate})log(rate). This is helpful, because log⁡(rate)\log(\text{rate})log(rate) lies in [−∞,∞][-\infty, \infty][−∞,∞].

The inverse of log⁡()\log()log() is the exponential function, which looks like this:

The rate is therefore modelled as exp⁡()\exp()exp() of the linear predictor. To go back from the rate to the linear predictor again, you use log⁡()\log()log().

This means that:

The intercept is interpreted as: the modelled log⁡()\log()log() of the rate, when all the other predictors are 000; and

The other parameters are interpreted as: "the change in log⁡(rate)\log(\text{rate})log(rate) associated with a unit increase in the predictor."
