# Congratulations!

You've written a useful set of functions to investigate two dice - including

- a function to simulate the sum of two dice (even if the die are not fair)
- a "likelihood" function that computes the actual theoretical distribution.

In other words you're well on your way to becoming a fully-fledged **bayesian statistician**.
What you need next is [Bayes theorem](../bayes.md).
