# Why do longer chromosomes have lower GC content?

In this section we ask you to investigate an apparent association chromosome length and GC content (the proportion of
chromosome bases that are 'G' or 'C', rather than 'A' or 'T'), using linear regression.

The suggested plan of attack is:

1. [Load and inspect the data](./data.md);
2. Try [estimating the relationship](./first_fit.md) between chromosome length and gc content in humans;
3. Try to see if this [replicates in other primates](other_primates.md)
4. Try to see if the fit is [explained by other variables in the data](./other_covariates.md)

Go [here](./data.md) to get started.
