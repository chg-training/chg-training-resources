# Four regression challenges

The best way to learn how to use regression is... to use regression!

With that in mind we now have (*up to*) four regression challenges for you to have a go at.  They are:

| Challenge question | Type of regression model | Link |
| ------------------ | ------------------------ | --------- |
| Is chromosome length associated<br/>with GC content? | Linear | *under construction* |
| Are *ATP2B4* genotypes associated<br/>with gene expression? | Linear | *under construction* |
| Are ABO blood group phenotypes<br/>associated with protection against malaria? | Logistic | See [this page](./abo/README.md) |
| How effective are malaria vaccines? | Poisson | *under construction* |
