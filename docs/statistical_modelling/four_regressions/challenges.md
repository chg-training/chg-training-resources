# Four regression challenges

The best way to learn how to use regression is... to use it!

With that in mind we now have four regression challenges for you to have a go at.  They are:

| Challenge question | Type of regression model | Link |
| ------------------ | ------------------------ | --------- |
| Is chromosome length associated<br/>with GC content? | Linear | *link tbc* |
| Are *ATP2B4* genotypes associated<br/>with gene expression? | Linear | *link tbc* |
| Are ABO blood group phenotypes<br/>associated with protection against malaria? | Logistic | See [this page](./abo/README.md) |
